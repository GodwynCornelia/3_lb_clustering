# Лабораторная работа №3. Кластеризация данных

Исследование Mobile Price Classification: сравнение K-Means и Gaussian Mixture на семи аппаратных характеристиках смартфонов. Ценовой класс `price_range` исключён из обучения и используется для внешней оценки готовых разбиений.

Основной отчёт — [Lab3_Clustering.ipynb](Lab3_Clustering.ipynb). Он содержит выполненные расчёты, графики, таблицы и пояснения после каждого вычислительного блока. Для просмотра и запуска можно использовать Jupyter или VS Code с расширением Jupyter.

## Воспроизведение

Окружение: Windows, Python 3.13. Команды PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe build_notebook.py
.\.venv\Scripts\python.exe verify_notebook.py
.\.venv\Scripts\python.exe -m unittest -v
```

Первое получение общедоступного `train.csv` выполняется через `kagglehub` и требует доступа к Kaggle. Последующие запуски используют кэш. Ноутбук самодостаточен: для выполнения всех его ячеек соседние Python-файлы не нужны.

`build_notebook.py` выполняет расчёты в чистом ядре и сохраняет отчёт. `report_analysis.py` содержит исходники пояснений; `results.json` — их сохранённую численную сводку. Если данные или параметры изменены, повторный запуск `build_notebook.py` обновляет и вычисления, и текстовые выводы. Обычный Run All пересчитывает код, но не изменяет сохранённые Markdown-ячейки.

## Содержание исследования

Описательные статистики, Шапиро–Уилк, корреляции и коэффициенты вариации, IQR/Z-диагностика, винзоризация, Hopkins с равномерным контролем, сравнение трёх способов масштабирования, матрица рассеивания, подбор числа групп и силуэтные профили, дендрограмма, внутренние и внешние метрики, венгерское сопоставление меток, чувствительность к параметрам, PCA и физические портреты центров.

Четыре группы рассматриваются как модель подробной технической сегментации. Оптимум внутренних метрик приведён отдельно: максимум силуэта при k=2 не подменяется утверждением об оптимальности k=4. Технические группы слабо восстанавливают ценовые классы; это отражено в результатах и заключении.

Команды и результаты проверок: [docs/VALIDATION.md](docs/VALIDATION.md).
