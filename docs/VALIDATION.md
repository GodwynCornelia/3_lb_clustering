# Проверка воспроизводимости

Окружение: Windows, Python 3.13.2, отдельная `.venv`. Точные версии библиотек приведены в `requirements-lock.txt` и приложении ноутбука.

## Выполненные проверки

| Команда | Результат |
| --- | --- |
| `.\.venv\Scripts\python.exe -m pip check` | `No broken requirements found.` |
| `.\.venv\Scripts\python.exe -m unittest -v` | Четыре теста, OK: Hopkins на равномерном и кластеризованном контроле, сопоставление переставленных меток, обработка лишних кластеров, точное ожидание RI в сравнении с полным перебором перестановок. |
| `.\.venv\Scripts\python.exe -m py_compile build_notebook.py clustering_utils.py report_analysis.py test_clustering_utils.py verify_notebook.py` | Успешная компиляция. |

После каждой кодовой ячейки проверяется наличие отдельного пояснения. Схема файла проверена через `nbformat`, исходники всех ячеек компилируются. Визуально проверены русские подписи, единицы измерения и шкалы на рисунках.

При первичной установке возникал конфликт доступа WinError 32 к файлу Jedi при перекрытии двух установок. После завершения установки проверка совместимости пакетов успешна. Windows/ZMQ выдаёт диагностическое сообщение о цикле событий; при запуске через PowerShell код Python проверяется явно:

```powershell
.\.venv\Scripts\python.exe build_notebook.py *> build.log
$buildExit = $LASTEXITCODE
Write-Output "Python exit code: $buildExit"
exit $buildExit
```

## Контрольные результаты

- 2000 устройств, 20 исходных характеристик; семь признаков в основном сравнении.
- Hopkins со степенью d: 0.9067; без степени: 0.5329; равномерный контроль в среднем 0.5002.
- K-Means: силуэт 0.1144, ARI 0.0207, Jaccard macro 0.1865.
- GMM full: силуэт 0.0910, ARI 0.0086, Jaccard macro 0.1714.
- Ожидаемый случайный RI с сохранением размеров групп: K-Means 0.625063, GMM 0.623948. Превышение наблюдаемого RI: 0.007749 и 0.003235 соответственно.
- Максимум силуэта при k=2, эвристика локтя даёт k=5. Четыре группы — исследуемая модель, а не доказанный оптимум.

При повторных запусках численные результаты совпали. В таблицу добавлены точное E[RI] при случайной перестановке меток с сохранением размеров групп и превышение наблюдаемого RI над этим ориентиром. Ожидание проверено полным перебором на выборке из пяти объектов: E[RI]=0.48. Для четырёх примерно равных групп ориентир составляет около 0.625.

Границы винзоризации в обработке и в `clip_details` берутся из исходной `X_selected`: px_height 15.00–1791.01, 39 замен. Нули px_height остаются в исходной таблице, но в рабочей заменяются нижней границей; это ограничение хвоста, а не восстановление измерений. Фронтальная камера `fc` диагностируется (18 IQR-флагов, 12 Z-флагов), но исключена из выбранных признаков и не винзоризируется. В пояснениях отдельно указаны ограничения k=4, GMM full, Hopkins power=1 и потеря 63.34% дисперсии в PCA-проекции.

Проверка после добавления случайного ориентира RI: все исходные столбцы метрик и таблица геометрии совпали с предыдущей версией; добавлены только два столбца RI. Полный запуск: Python exit code 0. `verify_notebook.py`: 62 ячейки, 25 выполненных кодовых ячеек, 15 рисунков, ошибок и незаполненных аналитических блоков нет.
