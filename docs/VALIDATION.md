# Проверка воспроизводимости

Окружение: Windows, Python 3.13.2, отдельная `.venv`. Точные версии библиотек приведены в `requirements-lock.txt` и приложении ноутбука.

## Выполненные проверки

| Команда | Результат |
| --- | --- |
| `.\.venv\Scripts\python.exe -m pip check` | `No broken requirements found.` |
| `.\.venv\Scripts\python.exe -m unittest -v` | Три теста, OK: Hopkins на равномерном и кластеризованном контроле, сопоставление переставленных меток, обработка лишних кластеров. |
| `.\.venv\Scripts\python.exe -m py_compile build_notebook.py report_analysis.py verify_notebook.py` | Успешная компиляция. |
| `.\.venv\Scripts\python.exe build_notebook.py` | Выполнение в чистом ядре, код завершения Python 0. |
| `.\.venv\Scripts\python.exe verify_notebook.py` | 62 ячейки, 25 выполненных кодовых ячеек, 15 рисунков, ошибок и незаполненных аналитических блоков нет. |

После каждой кодовой ячейки проверяется наличие отдельного пояснения. Схема файла проверена через `nbformat`, исходники всех ячеек компилируются. Визуально проверены русские подписи, единицы измерения и шкалы на рисунках.

При первичной установке возникал конфликт доступа WinError 32 к файлу Jedi при перекрытии двух установок. После завершения установки проверка совместимости пакетов успешна. Windows/ZMQ выдаёт диагностическое сообщение о цикле событий; при запуске через PowerShell код Python проверяется явно:

```powershell
.\.venv\Scripts\python.exe build_notebook.py *> build.log
$buildExit = $LASTEXITCODE
Write-Output "Python exit code: $buildExit"
exit $buildExit
```

## Контрольные результаты

- 2000 устройств, 20 исходных характеристик; семь признаков в основном сравнении.
- Hopkins со степенью d: 0.9067; без степени: 0.5329; равномерный контроль в среднем 0.5002.
- K-Means: силуэт 0.1144, ARI 0.0207, Jaccard macro 0.1865.
- GMM full: силуэт 0.0910, ARI 0.0086, Jaccard macro 0.1714.
- Максимум силуэта при k=2, эвристика локтя даёт k=5. Четыре группы — исследуемая модель, а не доказанный оптимум.

При повторных запусках численные результаты совпали. Изменения текста и подписей не изменили таблицы метрик и геометрических характеристик.
